# Dữ liệu

Nội dung thư mục này không đưa lên git.

- `calib/`: ảnh bảng hiệu chuẩn camera.
- `raw/`: ảnh bia chụp trên sa bàn, chưa gán nhãn.
- `dataset/`: dataset định dạng YOLO (`images/`, `labels/`, `data.yaml`), chia train/val/test.
- `eval/`: tập ảnh kiểm tra chụp riêng cho các bài đo ở mục 7 của kế hoạch.
