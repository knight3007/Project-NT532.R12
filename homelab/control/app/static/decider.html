Cách bật worker trên Colab
  1. Mở Colab, chọn runtime GPU (L4 hoặc A100).
  2. Cách 1: mở homelab/colab/colab_worker.ipynb, chạy lần lượt ô cấu hình (nhập token bằng getpass), ô cài đặt, ô xem log.
  3. Cách 2: dùng Colab CLI (kích hoạt colab_env\Scripts\activate trước): 
    colab new --gpu L4
colab upload homelab/colab/bootstrap.sh /content/bootstrap.sh
colab exec "NT532_REPO_URL=... NT532_BRANCH=... NT532_HUB_WS=<URL bên dưới> \
  NT532_WORKER_TOKEN=... NT532_JEV_RUN=jev2 NT532_WEIGHTS_URL=... bash /content/bootstrap.sh"
colab exec "tail -n 50 /content/worker.log"
  4. Đợi trạng thái ở trên chuyển sang "Sẵn sàng", rồi bấm "Thử một quyết định".
