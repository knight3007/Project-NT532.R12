# Hiệu chuẩn

- `camera.yaml`: ma trận camera, hệ số méo và sai số chiếu lại của webcam (tuần 1).
- `servo.yaml`: bảng quy đổi góc sang độ rộng xung, điểm 0 và hệ số (tuần 2–3).
- `offsets.yaml`: offset từ tag đế vòi tới tâm quay và tới đầu laser (tuần 3).
- `water.yaml`: bảng bù tilt cho tia nước (tuần 3).

Ghi kèm ngày đo trong từng file. Hiệu chuẩn lại camera nếu đổi độ phân giải hoặc lấy nét.
